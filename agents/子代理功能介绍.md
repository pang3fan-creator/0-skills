## 规划类

| 代理                       | 作用                                                         | 何时调用                                                   |
| -------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------- |
| **dev-planner**            | 将需求拆解为可执行开发计划，含任务分解、依赖分析、时间估算。**不写代码，只做规划。** | 需要制定功能实现计划、创建开发路线图、组织复杂开发任务时   |
| **Product Manager** (Alex) | 全生命周期产品负责人：发现、战略、路线图、GTM、效果衡量。产出 PRD、机会评估、路线图。 | 需要明确产品方向、撰写 PRD、评估功能优先级、制定发布计划时 |

## 设计类

| 代理                   | 作用                                                         | 何时调用                                                     |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **UI Designer**        | 设计系统、组件库、像素级界面。产出设计 tokens、CSS 体系、响应式框架。 | 需要搭建设计系统、创建组件库、确保视觉一致性时               |
| **UX Architect**       | CSS 架构、布局框架、信息架构、开发者交付规范。含主题切换、无障碍基础。 | 需要建立 CSS 设计系统、定义布局结构、准备开发手本时          |
| **Workflow Architect** | 映射系统所有路径（正常流程+异常分支+失败恢复+交接合约）。产出 build-ready 的 workflow spec。 | 需要梳理复杂业务流程、设计 API 交互流程、预防边界和异常情况时 |

## 工程类

| 代理                   | 作用                                                         | 何时调用                                                   |
| ---------------------- | ------------------------------------------------------------ | ---------------------------------------------------------- |
| **Backend Architect**  | 可扩展系统设计、数据库架构、API 开发、云基础设施。产出服务架构、数据库 schema、API 设计。 | 需要设计后端架构、优化数据库、构建微服务、设计 API 时      |
| **Frontend Developer** | 现代前端实现（React/Vue/Angular），性能优化，无障碍访问，PWA。产出可复用组件。 | 需要实现前端界面、优化性能、确保无障碍合规时               |
| **Software Architect** | 系统设计、领域驱动设计、架构模式选型、ADR（架构决策记录）。强调权衡而非银弹。 | 需要做架构决策、设计系统边界、编写 ADR 时                  |
| **Security Engineer**  | 威胁建模、漏洞评估、安全代码审查、安全架构。覆盖 OWASP Top 10、API 安全、云安全。 | 需要安全审计、威胁建模、代码安全审查、CI/CD 安全门禁时     |
| **DevOps Automator**   | 基础设施即代码（Terraform）、CI/CD 流水线（GitHub Actions）、容器编排、监控告警。 | 需要搭建 CI/CD、自动化部署、配置监控、优化基础设施时       |
| **SRE**                | SLO/错误预算、可观测性（metrics/logs/traces）、宕机治理、容量规划。 | 需要定义 SLO、构建监控体系、优化系统可靠性、减少手动运维时 |

## 质量类

| 代理              | 作用                                                         | 何时调用                                                |
| ----------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| **code-reviewer** | AI 辅助代码审查：安全漏洞、性能优化、配置审查、代码质量。覆盖多语言。 | 需要代码审查、安全扫描、性能评估、PR 质量把关时         |
| **bug-analyzer**  | 深度执行流分析、根因调查。从症状反向追踪到根因，产出完整分析报告。 | 遇到难以定位的 bug、需要追踪执行路径、做根因分析时      |
| **API Tester**    | API 综合测试：功能测试、性能测试、安全测试、合约测试。使用 Playwright/k6。 | 需要 API 测试、性能基准测试、安全测试、CI/CD 集成测试时 |

---

**常用协作链**：`Product Manager` 出需求 → `dev-planner` 出计划 → `Workflow Architect` 出流程 spec → `Backend Architect` + `Frontend Developer` 实现 → `code-reviewer` 审查 → `API Tester` 测试 → `DevOps Automator` 部署 → `SRE` 保障
